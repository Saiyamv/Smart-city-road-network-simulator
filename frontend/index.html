About Smart City Road Network Simulator

This project is a Problem-Based Learning (PBL) system demonstrating graph data structures and shortest-path navigation algorithms.

Algorithms Implemented:

  • Dijkstra's Algorithm: Explores nodes by cumulative distance using a Min-Heap Priority Queue. Guarantees the mathematical global shortest path on non-negative weighted graphs. Complexity: O((V + E) log V).
  • A* Search: Employs an admissible & consistent scaled Euclidean heuristic f(n) = g(n) + h(n) to direct the search toward the destination, reducing the search space while guaranteeing the optimal route.

Architecture:

  • High-Performance Engine: C++17 weighted adjacency graph model (cpp/).
  • Backend API Bridge: Zero-dependency Node.js HTTP server (backend/server.js).
  • Frontend Visualization: Interactive SVG rendering with dynamic route tracing & offline client fallback (frontend/).
